# המחברות שלי 📒

אפליקציית סיכומים. יש לה גרסה למחשב (Windows) וגרסה לאייפון.

- **אייפון:** https://github.com/shalevd31/notebooks/releases/tag/iphone (קובץ `Notebooks.ipa`)
- **אתר / אפליקציית מסך הבית:** https://shalevd31.github.io/notebooks/
- **מחשב:** `dist\Notebooks-Setup-1.0.0.exe`

## ✨ נושא חדש עם Claude
1. בכל מחברת, בתוכן העניינים, לוחצים **"＋ נושא חדש עם Claude"**.
2. כותבים או מדביקים את החומר, או מצלמים דפים 📷. אפשר גם לצרף PDF.
3. Claude מכין דף סיכום בסגנון המחברת ומציג אותו. אם רוצים שינוי, פשוט כותבים לו.
4. לוחצים **"➕ הוספה למחברת"**.

הנושא נשמר בקובץ `docs/topics.json` ב-GitHub, ומופיע לבד בכל המכשירים: טלפון, מחשב ואתר. לא צריך לבנות או להתקין מחדש.

בדף של נושא כזה יש גם **"✏️ שינוי עם Claude"** ו-**"🗑 מחיקת הנושא"**.

**הגדרות ⚙️ (פעם אחת בכל מכשיר):** צריך מפתח API של Claude וטוקן של GitHub. הם נשמרים רק במכשיר עצמו, לא ב-GitHub.
- **מחשב:** הם נשמרים בקובץ `%APPDATA%\Notebooks\config.json`.
- **טלפון:** במחשב לוחצים ⚙️ ← **"העתקת קוד הגדרה למכשיר אחר"**, שולחים את הקוד לטלפון, ובטלפון מדביקים אותו ב-⚙️ ← **"החלת הקוד"**.

## התקנה במחשב
1. לחיצה כפולה על `Notebooks-Setup-1.0.0.exe`.
2. אם מופיע מסך כחול "Windows protected your PC", לוחצים על **More info** ואז על **Run anyway**. האזהרה מופיעה כי לתוכנה אין חתימה מסחרית בתשלום.
3. לוחצים Next / Install.
4. בסוף יופיע בשולחן העבודה ובתפריט התחל אייקון בשם **המחברות שלי**.

## אפליקציה לאייפון (קובץ IPA)
GitHub בונה את `Notebooks.ipa` לבד בכל שינוי בקוד, ומפרסם אותו בדף ה-release.

**התקנה עם iloader:**
1. מוודאים שמותקן **iTunes**.
2. מחברים את האייפון בכבל, כשהנעילה פתוחה, ופותחים את **iloader**.
3. מתחברים עם ה-Apple ID ומתקינים את `Notebooks.ipa`.
4. באייפון: **Settings ← General ← VPN & Device Management** ← לוחצים על המייל ← **Trust**.
5. אם מתבקש: **Settings ← Privacy & Security ← Developer Mode** ← מדליקים ← Restart.

⚠️ **כל 7 ימים** אפל מבטלת את החתימה של חשבון חינמי. מחברים בכבל ומתקינים שוב, או לוחצים Refresh ב-iloader. הסיכומים לא נמחקים.

## אפשרות נוספת לאייפון: אפליקציית מסך הבית (בלי כבל, בלי חידוש)
1. פותחים את הקישור ב-**Safari**.
2. לוחצים על כפתור השיתוף ⬆️ ובוחרים **"הוספה למסך הבית"**.
3. מוודאים שהמתג **"פתח כאפליקציה רשת"** דולק, ולוחצים **"הוסף"**.

## שינויים בקוד עצמו
1. עורכים את `docs/index.html`, או את `src/nb-ai.js` ואז מריצים `npm run bundle`.
2. מעלים את `CACHE_VERSION` ב-`docs/sw.js`.
3. מריצים `git push`. ה-IPA החדש מוכן אחרי כ-10 דקות, ומתקינים אותו עם iloader.
4. למחשב מריצים `npm run dist` ומתקינים מחדש.

## פקודות
| פקודה | מה היא עושה |
|---|---|
| `npm install` | התקנה ראשונית של הכלים |
| `npm start` | פותח את האפליקציה למחשב בלי להתקין |
| `npm run bundle` | בונה את `docs/vendor/nb-ai.js` (הצ'אט עם Claude והסנכרון) |
| `npm run dist` | בונה את קובץ ה-Setup לתיקייה `dist` |
| `npm run icons` | מייצר את האייקונים מחדש מתוך `docs/icons/icon.svg` |
| `npm run fonts` | מוריד מחדש את הגופנים |
