# המחברות שלי 📒

אפליקציית סיכומים. יש לה גרסה למחשב (Windows) וגרסה לאייפון.

- **אייפון:** https://shalevd31.github.io/notebooks/
- **מחשב:** `dist\Notebooks-Setup-1.0.0.exe`

## התקנה במחשב
1. לחיצה כפולה על `Notebooks-Setup-1.0.0.exe`.
2. אם מופיע מסך כחול "Windows protected your PC", לוחצים על **More info** ואז על **Run anyway**. האזהרה מופיעה כי לתוכנה אין חתימה מסחרית בתשלום.
3. לוחצים Next / Install.
4. בסוף יופיע בשולחן העבודה ובתפריט התחל אייקון בשם **המחברות שלי**.

## התקנה באייפון
1. פותחים את הקישור ב-**Safari**, או סורקים את קוד ה-QR עם המצלמה.
2. לוחצים על כפתור השיתוף (הריבוע עם החץ למעלה ⬆️). ב-iOS 18 ומעלה הוא נמצא בתפריט שלוש הנקודות (···) למטה.
3. גוללים ובוחרים **"הוספה למסך הבית"**.
4. מוודאים שהמתג **"פתח כאפליקציה רשת"** דולק, אם הוא מופיע, ולוחצים **"הוסף"**.
5. פותחים את האפליקציה מהאייקון החדש פעם אחת כשיש אינטרנט. מאותו רגע היא עובדת גם בלי אינטרנט.

## הוספת חומר חדש
1. ב-`docs/index.html`:
   - מוסיפים נושא למחברת במערך `NOTEBOOKS`, למשל `{ id:'motor', title:'מנוע', pages:'3–4' }`.
   - מוסיפים `<template id="t-motor">` עם הדפים, בדיוק כמו `t-transformer`.
2. ב-`docs/sw.js` מעלים את `CACHE_VERSION`, למשל ל-`'v2'`.
3. מעדכנים את הטלפון:
   ```
   git add -A
   git commit -m "נושא חדש"
   git push
   ```
   אחרי דקה או שתיים האפליקציה בטלפון מתעדכנת לבד בפתיחה הבאה.
4. מעדכנים את המחשב: מריצים `npm run dist` ומתקינים שוב את ה-Setup החדש.

## פקודות
| פקודה | מה היא עושה |
|---|---|
| `npm install` | התקנה ראשונית של הכלים |
| `npm start` | פותח את האפליקציה למחשב בלי להתקין |
| `npm run dist` | בונה את קובץ ה-Setup לתיקייה `dist` |
| `npm run icons` | מייצר את האייקונים מחדש מתוך `docs/icons/icon.svg` |
| `npm run fonts` | מוריד מחדש את הגופנים |
